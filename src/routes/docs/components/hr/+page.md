# Hr

Display a divider that separates content areas in your email.

## Usage

```svelte
<script>
	import { Hr } from 'svelte-email';
</script>

<Hr />
```

## Props

| Name    | Type     | Required | Description                                            |
| ------- | -------- | -------- | ------------------------------------------------------ |
| `style` | `object` | `false`  | Style object that will be applied to the `hr` element. |
