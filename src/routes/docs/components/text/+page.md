# Text

A block of text separated by blank spaces.

## Usage

```svelte
<script>
	import { Text } from 'svelte-email';
</script>

<Text>Hello, world!</Text>
```

## Props

| Name    | Type     | Required | Default | Description      |
| ------- | -------- | -------- | ------- | ---------------- |
| `style` | `object` | `false`  |         | Inline CSS style |
