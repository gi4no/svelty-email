# HTML

A Svelte html component to wrap emails.

## Usage

```svelte
<script>
	import { Html } from 'svelte-email';
</script>

<Html lang="en">
	<!-- ... -->
</Html>
```

## Props

| Name   | Type     | Description                |
| ------ | -------- | -------------------------- |
| `lang` | `string` | The language of the email. |
